# pejabat.id untuk macOS

Aplikasi macOS untuk [pejabat.id](https://pejabat.id), direktori profil pejabat publik Indonesia.

Aplikasi ini memuat situs pejabat.id di jendelanya sendiri, jadi isinya selalu mengikuti versi situs terbaru.

## Unduh

Buka halaman [Rilis](../../releases/latest), unduh berkas `.dmg`, lalu seret `pejabat.id` ke folder Applications.

Berjalan di macOS 12 atau lebih baru, untuk Mac berprosesor Apple maupun Intel.

## Saat pertama dibuka

Aplikasi ini belum dinotarisasi Apple. macOS akan menolak membukanya pada percobaan pertama. Untuk mengizinkannya:

1. Buka aplikasinya sekali, lalu tutup peringatannya.
2. Buka Pengaturan Sistem, pilih Privasi & Keamanan.
3. Di bagian Keamanan, tekan Tetap Buka untuk pejabat.id.

Di macOS 12, jalurnya Preferensi Sistem, Keamanan & Privasi, lalu tab Umum.

## Pembaruan

Aplikasi memeriksa versi baru sendiri dan memasangnya di latar. Versi baru berlaku saat aplikasi dibuka lagi. Pemeriksaan manual ada di menu pejabat.id, Periksa Pembaruan.

Setiap pembaruan bertanda tangan. Aplikasi menolak memasang berkas yang tanda tangannya tidak cocok.
